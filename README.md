# Amigos da Turma - Challenge Turma do Bem x FIAP

Plataforma digital desenvolvida para ampliar a captação e o relacionamento com doadores Pessoa Física (PF) da OSCIP Turma do Bem. O projeto foca na conversão de doações pontuais em recorrentes, proporcionando uma jornada simples, transparente e alinhada à LGPD.

## 💻 Tecnologias Utilizadas (Sprint 1)
* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização baseada na identidade visual da ONG (Verde `#009639` e Laranja `#F26522`), utilizando Flexbox e CSS Grid.
* **Git e GitHub:** Versionamento de código e fluxo de trabalho seguro via *Feature Branching* e *Pull Requests*.

## 🚀 Como Executar o Projeto
1. Faça o clone deste repositório no seu terminal:
   `git clone [https://github.com/NextByte-1TDSPT/AmigosDaTurma.git]`
2. Abra a pasta `amigos-da-turma` no seu editor de código (ex: VS Code).
3. Dê um duplo clique no arquivo `index.html` para abri-lo no seu navegador padrão.
